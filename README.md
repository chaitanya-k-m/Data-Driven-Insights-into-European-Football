# Data-Driven Insights into European Football

## Description
This project analyzes European football trends using data science. It explores **PSG’s rise post-QSI, Manchester United’s decline after Ferguson, Dortmund’s struggles, and La Liga’s predictability**. Using **Python, SQL, and visualizations**, it uncovers data-driven insights into team performance and league dynamics.

## Dataset
- The dataset is sourced from **Kaggle**: [European Soccer Database](https://www.kaggle.com/datasets/hugomathien/soccer).
- It contains match records, player stats, and team data from **2008 to 2015**.

## Key Analysis Topics
1. **Ligue 1: PSG’s Transformation Post-QSI Takeover**
   - Performance changes before and after **Qatari Sports Investments (QSI) takeover** in 2011.
   - **Metrics analyzed:** Win rate, goals scored/conceded.

2. **La Liga: Predictability of Match Outcomes**
   - Examining the **entropy of match results** and the dominance of Barcelona & Real Madrid.

3. **Bundesliga: Borussia Dortmund’s Performance Decline**
   - Investigating Dortmund’s **2014/15 struggles compared to 2011/12**.
   - **Factors analyzed:** Goal scoring, injuries, managerial changes.

4. **Premier League: Manchester United’s Post-Ferguson Era Decline**
   - Comparing **Manchester United’s performance** before and after **Sir Alex Ferguson’s retirement**.
   - **Findings:** 25% decline in goals scored, increased losses.

5. **Serie A: Defensive Strength as a Key to Victory**
   - Do teams with the most **clean sheets** have a higher chance of winning the league?
